# Stumps (그루터기)

모델을 넣으면 기존 원기둥 그루터기가 자동으로 이 모델로 바뀐다:
- 추천: Poly Haven "Tree Stump 01" https://polyhaven.com/a/tree_stump_01 , "Pine Roots" https://polyhaven.com/a/pine_roots (둘 다 CC0, 로그인 불필요)
- 받는 법: FBX (권장, Unity가 바로 읽음)로 다운로드.
- 넣는 곳: 이 폴더(Assets/Resources/Stumps/)에 .fbx 파일을 통째로 넣는다.
- 크기는 자동 보정: 실행 중 기존 그루터기 자리의 크기에 맞춘다.
