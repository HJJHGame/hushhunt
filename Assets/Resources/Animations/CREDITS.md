# Animations 에셋 출처

- `UAL1_Standard.fbx` — "Universal Animation Library" by Quaternius
  - 소개 페이지: https://quaternius.com/packs/universalanimationlibrary.html
  - 다운로드: https://quaternius.itch.io/universal-animation-library
  - 라이선스: CC0 1.0 (퍼블릭 도메인, 저작자 표시 불필요, 상업적 사용 가능)
  - Standard(제자리) 버전 사용, 루트 모션(_RM) 버전은 미포함
  - 사용 클립: Idle_Loop, Walk_Loop, Jog_Fwd_Loop, Sprint_Loop, Jump_Start, Jump_Loop, Jump_Land, Crouch_Idle_Loop, Crouch_Fwd_Loop
  - 릭 참고: Unreal식 본 이름(pelvis, spine_01, upperarm_l 등)을 쓰므로 Generic 임포트로는
    캐릭터(Mixamo식 본)에 바인딩되지 않음 → 둘 다 Humanoid 임포트로 리타깃 (.meta 참조)
