# Hush Hunt

3:3 비대칭 온라인 데스매치. 어둡고 축축한 밤의 숲에서 숨는 팀과 잡는 팀이 서로를 사냥합니다. 데스매치 + 숨바꼭질 + 술래잡기. (프로토타입, 가제)

## 게임 소개

- 1인칭 3:3 비대칭 숨바꼭질 FPS. 한 팀은 숨고 다른 팀(술래)은 찾아서 잡습니다.
- 서로가 서로의 사냥감입니다. 숨는 팀도 총으로 술래를 죽일 수 있습니다.
- 캐릭터: 마인크래프트 비율의 블록 인간형(머리 8, 몸통 8x12x4, 팔다리 4x12x4)을 기본 도형으로 만듭니다. 봇과 다른 플레이어가 같은 몸을 씁니다.
- 숲 배치: 나무는 총 1800그루입니다. 맵을 8m 칸으로 나눠 칸마다 한 그루씩 먼저 심고(큰 빈터가 안 생김), 나머지는 기존 나무와 3.2m 이상 떨어진 곳 중 가장 한적한 곳에 심습니다. 봉쇄 구역 5곳, 집, 스폰 주변에는 심지 않습니다. 종류별 개수는 정확히 맞춥니다: 죽은 가문비 900, 낙우송(가장 큰 나무) 80, 어린 가문비 820.
- 분위기: 어두운 밤, 가는 나무가 늘어선 축축한 공포 숲. 나무의 절반(900그루)은 잎 없는 죽은 나무이고, 나머지는 잎 있는 가문비와 이끼 낀 낙우송입니다. 안개는 없고, 시야는 어둠이 제한합니다.
- 소리로 상대의 위치를 읽는 정보 싸움이 핵심입니다. 발소리, 총소리, 심장박동이 단서입니다.

## 기본 규칙

- 3:3, 모든 플레이어 체력 100.
- 맵: 300x300m 숲 (크기는 변수로 조절, 집은 예정).
- 한 판 10분 = 숨는 시간 60초 + 수색 9분.
- 부활, 체력 회복, 재장전, 아군 사격 없음.

## 진행

숨는 시간 (60초)
- 숨는 시간 동안 술래는 움직일 수 없고(시점만 돌림), 쏠 수 없으며, 지도를 봐도 자기 위치 표시와 X 좌표는 뜨지 않습니다.
- 술래는 맵에 없습니다. 술래 화면은 검은 화면에 타이머와 소리뿐입니다.
- 술래가 듣는 소리는 숨는 팀 한 명의 움직임 소리입니다. 술래마다 독립적으로 랜덤 배정되고 중복될 수 있으며, 누가 누구 소리를 듣는지는 비공개입니다. (예정)
- 숨는 팀은 시작할 때 무기를 하나씩 랜덤으로 받습니다 (권총, 소총, 칼, 중복 가능). 시작 위치는 봉쇄 구역 밖 랜덤입니다.
- 맵의 5곳(네 모퉁이와 정중앙)에 15x15m 구역이 있고, 돌벽으로 막혀 있어 숨는 팀은 들어갈 수 없습니다.
- 이 시간에는 누구도 피해를 입지 않고, 발사도 할 수 없습니다.

수색 시작
- 돌벽 5곳이 동시에 한 번에 사라집니다. 돌 가는 2D 효과음이 4초 나옵니다 (방향 없음, 전원 동일).
- "술래가 스폰되었습니다" 문구가 뜹니다.
- 술래 3명은 5곳 중 랜덤 한 곳에서 같이 시작하며, 구역 안의 서로 다른 3개 위치에 섭니다. 효과음이 끝날 때까지 움직일 수 없습니다.
- 심장박동은 이때부터 작동합니다.

## 전투

| | 술래 | 숨는 팀 |
|---|---|---|
| 사망까지 | 2발 (피해 50) | 3발 (피해 34) |
| 탄약 | 6발 | 4발 |

- 소총: 볼트액션 소총 모양. 고정 피해, 사거리 제한 없음, 탄 퍼짐 약간.
- 권총: 한 발 직선 판정, 사거리 60m, 거리와 상관없이 고정 피해, 탄 퍼짐 아주 약간.
- 칼: 마체테 모양. 사거리 2m, 쿨다운 1초, 1타 = 총알 1발 피해. 탄약 없음.
- 1인칭 화면에서 손에 든 무기는 실물 모양입니다 (권총, 볼트액션 소총, 마체테). 쏘면 뒤로 살짝 밀립니다.
- 술래는 총을 버릴 수 없습니다. 탄이 떨어지면 도망만 갈 수 있습니다.
- 죽은 사람의 총 드랍은 없습니다. (예정: 나중에 넣으면 누구나 F로 줍기)

## 종이와 술래의 총

- 맵에 종이가 10장 있고, 나무 한 그루에 한 장씩 붙어 있습니다. 종이는 낙우송 80그루 중 10그루에만 붙습니다.
- F를 3초 꾹 눌러 줍습니다. 찾은 술래는 바로 소총을 받습니다. 한 사람이 종이를 두 번 찾을 수 없습니다.
- 첫 종이가 발견되고 1분 뒤에는 총이 없는 술래도 자동으로 랜덤 무기를 받습니다.
- 종이를 줍는 소리나 연출은 없습니다. 숨는 팀은 술래가 총을 받았는지 알 수 없습니다.

## 소리

- 총소리: 맵 전체에서 들리고 방향이 있습니다. 거리에 따라 볼륨만 줄어듭니다.
- 발소리가 들리는 범위: 달리기 25m, 기본 12m, 천천히 걷기 5m. 앉은 상태는 움직일 수 없으므로 정지 중에는 소리가 나지 않습니다.
- 다른 사람의 발소리는 이 범위 안에서만, 방향과 거리감(멀수록 작게)을 가지고 들립니다. 테스트 봇의 발소리는 기본 걸음 12m입니다. (구현됨)
- 환경 소음(바람, 새, 나뭇가지)이 발소리를 가립니다. (예정)
- 심장박동: 숨는 팀이 듣습니다. 가장 가까운 술래가 15m 안에 오면 시작되고, 가까울수록 커집니다. 방향은 알 수 없습니다.
- 킬로그: 유저네임만 표시합니다. (예정)

## 시야와 손전등

- 손전등을 켜면 20m, 끄면 10m까지 보이고, 그 너머는 완전한 어둠입니다.
- 손전등은 T로 켜고 끕니다. 배터리는 무제한, 깜빡임 없음.
- 켜진 손전등은 거리 제한 없이 멀리서도 빛의 점으로 보입니다.

## 이동

| 동작 | 키 | 속도 (m/s) |
|---|---|---|
| 기본 | WASD | 4 |
| 달리기 | Shift | 6 |
| 천천히 걷기 | Ctrl | 2.5 |
| 웅크리기 | C | 가만히 있을 때만 유지, 움직이면 풀림 |
| 점프 | Space | 높이 약 1.2m |

모든 플레이어의 이동 속도는 같습니다.

## 승리 조건

- 술래 승리: 숨는 팀 전멸.
- 숨는 팀 승리: 술래가 살아 있는 채로 시간 종료.
- 술래가 전멸하면: 처음 술래가 스폰할 수 있던 5곳 중 랜덤 한 곳이 탈출구가 되고, 위치가 전원에게 공개됩니다. 살아 있는 숨는 팀 전원이 시간 안에 그 구역에 들어가 3초 꾹 눌러 탈출해야 승리합니다. 시간 안에 못 나가면 숨는 팀이 집니다.

## 사망 후

- 같은 팀 생존자의 시점으로만 관전합니다. 상대 팀을 방해할 수 없습니다.
- 관전 중 소리는 관전 대상 기준입니다.
- 시체는 사라지지 않고 남습니다 (공포 요소). 시체는 이동과 총알을 막습니다.

## 조작키

인벤토리는 항상 화면 아래 가운데에 보이고, 가진 것만 고정 순서(종이, 칼, 권총, 소총)로 칸이 생깁니다. 얻은 순서와는 상관없고, 손전등은 항상 들고 있어서 칸에 없습니다.

| 키 | 동작 |
|---|---|
| F | 상호작용 (종이 줍기, 탈출. 문은 예정) |
| C / Ctrl / Shift | 웅크리기 / 천천히 걷기 / 달리기 |
| Space | 점프 |
| T | 손전등 |
| X | 좌표 표시 |
| 좌클릭 | 발사, 공격 |

테스트용 키: O 탈출구 열기, G 팀 전환, H 자기 피격, R 재시작.

테스트용 봇: 혼자 테스트할 때 플레이어는 잡는 팀(봉쇄 구역 안), 봇은 숨는 팀으로 시작합니다. 몸이 빛나고(숨는 팀 청록, 잡는 팀 빨강 기운) 계속 돌아다니며 쏘지는 않습니다. G를 누르면 봇과 팀과 위치가 서로 바뀝니다. 피해, 숨는 시간, 사망, 관전 규칙은 플레이어와 같습니다.

## 삭제된 규칙

후반 종소리, 종이 소리, 안개, 손전등 깜빡임, 손전등 배터리, 술래 속삭임, 스폰 안전거리, 가장자리 탈출구.

## 예정 / 보류

보급품, 죽은 후 방해, 문 열고 닫기, 총소리 외 연출, 온라인 멀티플레이, 집 추가. (싱글 테스트용 봇은 구현됨)
알려진 위험: 술래를 살려두고 버티기만 해도 숨는 팀이 이길 수 있어서, 숨는 팀이 싸우지 않을 수 있습니다. 플레이테스트에서 먼저 확인합니다.

## 개발 상태

Unity 6로 개발 중인 프로토타입입니다. Steam 출시가 목표입니다. 규칙과 수치는 플레이테스트를 거치며 바뀔 수 있습니다.
