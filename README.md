# Hush Hunt

3:3 비대칭 온라인 데스매치. 안개 짙은 밤의 숲에서 숨는 팀과 잡는 팀이 서로를 사냥합니다. 데스매치 + 숨바꼭질 + 술래잡기. (프로토타입, 가제)

## 게임 소개

- 1인칭 3:3 PvP, 한 팀은 숨고 다른 팀은 잡습니다.
- 서로가 서로의 사냥감입니다. 숨는 팀도 총으로 잡는 팀을 죽일 수 있습니다.
- 분위기: 짙은 안개, 어두운 밤, 가는 소나무가 늘어선 공포 숲.
- 소리와 지도로 상대의 위치를 읽는 정보 싸움이 핵심입니다. 걸으면 발소리가, 총을 쏘면 총알 위치가 지도에 표시됩니다.

## 규칙

숨는 팀
- 시작 후 1분간 숨는 시간이 따로 주어집니다.
- 무기: 샷건(2발), AR(약 10발), 발차기(피해 없이 밀어내기만)

잡는 팀
- 시작 시 호루라기만 갖고 있습니다. 위치를 알릴 수만 있고 죽일 수는 없습니다.
- 나무에 걸린 종이를 먹으면 한 명이 스나이퍼(2~3발, 어디를 맞춰도 한 방)로 무장합니다.
- 나머지 두 명은 게임 시간 1분이 지날 때마다 한 명씩 추가로 무장합니다.

승리 조건
- 상대 팀 전멸
- 폭탄 타이머가 끝나면 잡는 팀 승리 (예: 5분)
- 숨는 팀은 목표물 확보로도 승리 (검토 중)

사망하면 바로 탈락하고 본인 팀 시점으로 관전합니다.

초반에는 숨는 팀이, 후반에는 잡는 팀이 유리한 역전 구조입니다.

## 개발 상태

Unity 6로 개발 중인 프로토타입입니다. Steam 출시가 목표입니다. 규칙과 수치는 플레이테스트를 거치며 바뀔 수 있습니다.
